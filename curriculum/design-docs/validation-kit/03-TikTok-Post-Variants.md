# 03 — TikTok Concept Post (3 caption variants)

**Goal:** drop the 60-second concept video on TikTok with a caption that earns plays + favorites + "when does it launch?" comments. Day-30 floor: 1,000+ plays OR 10+ launch-question comments.

**Post timing:** Sunday or Tuesday between 19:00-21:00 SAST. SA TikTok engagement spikes here.

**Account:** post from a personal SA-coded account if you have one. If you create a new one (e.g., `@foundermode.za`), build credibility for 3-7 days first by liking + commenting on SA gaming, kasi-life, amapiano accounts. Cold accounts get throttled.

---

```
imagine if Roblox had a real Mzansi 🇿🇦

start with R500
build your spaza
talk to your customers (they'll tell you what they want)
read the day, run it back
stokvel up
spaza → salon → taxi rank → empire

founder mode: mzansi 👀
favorite the page to play first 🔗 [your Roblox link]

#robloxsa #ekasi #amapiano #foundermode #mzansi #robloxtycoon #soweto #bloxburg #adoptme #spaza #stokvel #tycoon
```

**Why it works:** opens with the question (forces engagement), no caps lock or excessive punctuation (kasi-Twitter-coded reads more authentic than corporate marketing), hashtags balance niche (kasi) + broad (Roblox tycoon meta).

## Recommended posting cadence

- **Day 1:** post Variant A on TikTok. Cross-post to IG Reels with same caption.
- **Day 2:** in TikTok comments, pin a comment from your own account: *"comment 'me' if you want a launch notification"* — this seeds the comment trigger you need for the day-30 floor.
- **Day 4-5:** post Variant B as a "follow-up" (different angle on the same video, or a 15s cut focusing on the stokvel frame). Caption: *"more on this. founder mode: mzansi soon."*
- **Day 7:** post Variant C if engagement on A+B was below 200 plays each. Sharpening the hook.
- **Daily for 14 days:** reply to every comment. Yes every. Comments boost the algorithm; replies double the boost.

---

## Comment-watch protocol (the actual signal)

Day-30 floor includes 10+ "when does it launch?" comments. To track:

Make a file: `~/Desktop/Founder-Mode-Validation-Kit/tiktok-comment-log.md`. Each row: *date — username — verbatim comment — type*.

Comment types to count:
- **A — "when launch?"** → hard demand signal
- **B — "this looks sick / lit"** → soft demand signal
- **C — tagged a friend** → strong demand signal (viral seed)
- **D — feature requests** → demand + product input ("can we have soccer too?", "add Lagos!")
- **E — cringe / dismissive** → counter-signal, count separately

If type A + C combined ≥ 10 by day 30, the demand gate is green. If type E outweighs A+B+C, the brand is mistuned — likely the cringe is in the brand name or the video tone.

---

## Reply scripts (use sparingly — sound like a person, not a brand)

- For "when launch?" → "🎯 working on it. favorite the roblox page for the drop"
- For "this looks sick" → "🙏 thanks bro/sis. share with someone who'd play"
- For tagged-a-friend → like the comment, no reply (lets the conversation breathe)
- For feature requests → "noting it. what would make it sick for you?" (turns input into a longer thread)
- For cringe / dismissive → ignore. Don't reply. Engagement, even negative, feeds the algorithm AND your ego — neither helps you.
- For "is this real?" → "🔧 building it. follow / favorite to see the drops"

---

## Pitfalls

- **Don't post without the Roblox link.** The whole point is to convert plays → favorites. No link = wasted virality.
- **Don't post during SA peak hours unless you can reply within 30 min.** First-hour engagement determines the algorithm's promotion budget for the post.
- **Don't fake-engage** (buy comments, recruit friends to comment). TikTok detects it; the post gets shadow-banned. Lose the algorithm = lose 90% of organic reach.
- **Don't pivot the brand mid-thread.** If the response is lukewarm, that's data. Don't rebrand after 100 plays.
- **Don't gate the favorites behind a join-Discord-first ask.** Friction = drop-off. The Roblox favorite must be the first action.
