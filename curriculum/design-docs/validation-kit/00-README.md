2. **Roblox stokvel policy** — written response or no-response status.
3. **DevEx + W-8BEN** — paperwork started.
4. **Roblox-native demand** — 100+ Roblox favorites OR 1,000+ TikTok plays OR 10+ "when it launches?" comments.

## Decision rule
- 3+ gates pass → proceed to v1 build, run `/plan-design-review` next.

- ≤ 1 gate passes → pause v1, revisit the design doc, possibly re-run `/office-hours`.
